El objetivo de este presente trabajo es lograr desarrollar un sistema que opere de manera autónoma una cartera con un valor de un millón de dolares
para obtener el mayor beneficio posible asumiendo el mínimo riesgo. Como se puede observar en la tabla anterior el sistema operará sobre 13 futuros
distintos que incluyen divisas, materias primas, índices bursátiles y bonos del Tesoro estadounidense, proporcionando así una exposición diversificada
a diferentes clases de activos y comportamientos de mercado.

Para lograr este objetivo he decidido desarrollar una arquitectura basada en modelos de aprendizaje automático que ayudan a decidir las acciones a
realizar, se emplea tanto modelos de aprendizaje supervisado como no supervisado, cada uno de ellos se detallará en los siguientes capítulos
correspondientes. Como resumen de la arquitectura se usarán modelos de aprendizaje profundo como modelos de aprendizaje supervisado y modelos
tradicionales

\notes{Justificar cambio de ML tradicional a DL}

El núcleo del sistema funciona de la siguiente manera

\begin{enumerate}
    \item Se cargan los datos minuto a minuto de uno de los futuros
    \item Se estandariza el tiempo que aparece en las muestras a UTC
    \item Se eliminan los datos que son claramente erróneos (fines de semana)
    \item Se recortan los dataset para tener los mismos periodos para todos los futuros
    \item Se añade el día de negociación al que pertenece cada dato
    \item[$\blacksquare$] Visualizar los datos originales limpios 
    \item Obtener la información actualizada de los diferentes futuros
    \item Muestreo de los datos en diferentes periodos
    \item Cálculo de los datos acumulados a partir de los datos originales
    \item Cálculo de las características que se usarán para entrenar los modelos de aprendizaje automático
    \item Analizar las nuevas características para revisar si la información tiene sentido
    \item Decidir algunas de las características que no se usarán manualmente por criterios como la no estacionalidad
    \item Calcular la variable objetivo que los modelos supervisados tratarán de predecir
    \item Filtrar más características usando modelos supervisados tradicionales que permitan mayor explicabilidad
    \item Calcular los parámetros que se utilizaran para definir el entrenamiento de los modelos
    \item Entrenar los modelos por separado
    \item Durante cada época del entrenamiento se usan los modelos no supervisado para detectar el régimen de mercado actual y usar esta información
    como características adicionales para el modelo
    \item Búsqueda de los umbrales de confianza más adecuados para cada modelo y evaluación de los resultados de la predicción usando métricas
    estandar de clasificación y métricas dedicadas de finanzas
    \item Guardar los mejores modelos
\end{enumerate}
